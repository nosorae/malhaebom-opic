# 0044. 복습 묶음은 결과까지 설정에 두고 복습 끝은 같은 화면에 그린다

- 상태: 채택
- 날짜: 2026-11-20

## 배경

복습 한 묶음은 6장이고 중간에 나가도 다음에 이어 간다(F18.8). 묶음을 끝내면 알았음, 다시, 처음 본 장 수를 보인다. 설계(design.md 12.4)는 이번 묶음의 카드 id 와 지금 순번을 설정 저장소에 둔다고만 정했다. 순번만 남기면 앱을 다시 켠 뒤 끝낸 묶음의 결과를 셀 수 없다. 평가는 카드 줄에 바로 쓰지만 카드 줄에는 마지막으로 누른 평가가 남지 않는다.

복습 끝은 요구사항에서 시트로 적었다. 평가 버튼의 어려움과 쉬움은 길게 눌러야 나온다(F18.6).

## 후보

1. 묶음을 카드 id 와 누른 결과 목록으로 설정 저장소에 두고, 순번은 결과 수로 센다. 복습 끝은 복습 화면 안에 그린다
2. 카드 id 와 순번만 두고, 결과는 화면이 들고 있다가 프로세스가 끝나면 잃는다
3. 묶음과 결과를 Room 표로 둔다
4. 복습 끝을 아래 시트로 띄운다

## 결정

1을 고른다.

- 설정 값 하나에 `카드 id 들|결과들` 로 둔다. 결과는 평가 이름이고 처음 봄 카드의 다음은 빈 칸이다
- 누를 때마다 카드 줄을 쓰고 묶음 결과를 더한다. 쓰기는 누른 순서대로 하나씩 한다
- 묶음을 끝낸 뒤 다시 열면 오늘 복습할 카드로 새 묶음을 만든다. 6장 더도 새 묶음이다
- 복습 끝은 같은 화면의 내용으로 그리고 6장 더와 끝내기를 아래에 둔다
- 평가 버튼을 길게 누르면 넷이 다 나오고, 그 아래 "길게 누르면 어려움과 쉬움이 나와요" 글자 버튼도 같은 일을 한다
- 소리 없이를 켜면 처음 봄 카드도 읽지 않는다

## 이유

2는 중간에 앱이 내려간 묶음의 끝 화면이 앞에서 누른 장을 빠뜨려 숫자가 틀린다. 3은 6개짜리 목록 하나에 표와 이전 SQL 을 더하는데, 출시 전 version 5 를 다시 고쳐야 한다. 설정 저장소는 두 플랫폼 모두 프로세스가 끝나도 남아서 1로 충분하다.

4는 시트를 끌어 내리면 뒤에 카드가 없는 빈 복습 화면이 남는다. 같은 화면에 그리면 닫을 길이 끝내기 하나라서 빈 화면이 생기지 않고, 스크린샷도 창 하나로 찍는다.

길게 누르기는 눈에 보이지 않아 처음 쓰는 사람은 모른다. 화면 읽기 도구 사용자도 길게 누르기를 찾기 어렵다. 같은 일을 하는 글자 버튼을 두면 두 경우 모두 어려움과 쉬움에 닿는다.

소리 없이는 소리를 낼 수 없는 자리에서 켠다. 처음 봄 카드만 읽으면 그 자리에서 소리가 난다.

## 결과

- 묶음 안의 남은 카드를 표현 탭에서 지우면 그 id 가 남아 묶음이 끝나지 않은 것으로 남는다. 다시 열면 남은 카드 없이 복습 끝을 보이고 6장 더로 이어 간다
- 이번 주 처음 복습한 날의 축하(F18.8)는 아직 그리지 않는다. 본 표시를 남길 곳과 함께 따로 더한다
- 복습 양을 고르는 설정 화면이 생기기 전까지 복습 양은 보통이다
