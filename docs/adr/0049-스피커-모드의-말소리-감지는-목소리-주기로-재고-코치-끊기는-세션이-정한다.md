# 0049. 스피커 모드의 말소리 감지는 목소리 주기로 재고 코치 끊기는 세션이 정한다

- 상태: 채택
- 날짜: 2026-11-20

## 배경

샤워처럼 이어폰을 못 쓸 때 스피커로 연습한다(F20). 물소리는 크기가 커서 지금의 말소리 판정(-40dB, F5.5)을 넘고, 에코 제거 뒤에도 코치 목소리가 조금 남는다. 그 소리를 그대로 보내면 서버 음성 감지가 말 시작으로 보고 코치를 스스로 끊는다. 그래서 기기 안에서 말소리가 아닌 조각을 거르고(F20.3), 코치가 말하는 중의 끊기는 기기가 정한다(F20.4).

## 후보

1. 학습된 감지 모델(Silero VAD)을 ONNX Runtime 으로 두 플랫폼에서 돌린다. 저장소의 LICENSE 파일은 MIT 다. README 배지의 대체 글은 CC BY-NC 로 적혀 엇갈리지만 배포 조건은 LICENSE 파일을 따른다
2. 플랫폼 기본 기능을 쓴다. iOS 는 Sound Analysis 의 소리 분류가 있지만 Android 에는 공개된 말소리 감지 API 가 없다
3. 목소리 높이 범위(70~400Hz)의 자기 상관으로 성대가 떠는 소리인지를 공통 코드에서 직접 잰다
4. 끊기 판정을 `libs/duplex-audio` 에 둔다
5. 끊기 판정을 `engine/speaking` 의 세션에 둔다

## 결정

3과 5를 고른다.

- `MicChunk.voiced` 는 말소리 크기이면서 목소리 주기 유사도가 `VOICED_SIMILARITY`(처음 0.5) 이상인 조각이다. 스피커 모드에서만 말소리 판정에 쓴다
- 코치가 말하는 중에는 조각을 보내지 않고 `BargeIn` 에 붙잡는다. 내 말소리가 `BARGE_IN_AFTER`(처음 0.6초) 넘게 이어지면 재생을 멈추고 붙잡은 조각부터 보낸다. 말소리 사이 `BARGE_IN_GAP`(0.2초)까지의 틈은 이어진 것으로 보되, 0.6초는 말소리 조각 길이만 더해 잰다. 끊기 전에 코치 말이 끝나면 붙잡은 조각을 먼저 보내 겹쳐 시작한 대답의 앞부분을 잃지 않는다
- 기기가 끊은 턴의 남은 코치 음성은 서버가 그 턴을 끝낼 때(끼어듦 또는 턴 끝)까지 버린다
- 설정의 말로 끊기가 꺼져 있으면 스피커 모드에서도 끊지 않고, 코치가 말하는 동안의 조각은 버린다
- 스피커 모드면 Live 연결의 말 시작과 끝 감도를 낮게 둔다(F20.5). 연결 경계(`SpeakingLink.connect`)가 소리 환경과 말로 끊기 값을 받는다. 세션이 `SpeakingSetup.bargeIn` 하나로 서버 끊기와 기기 끊기를 같이 정해 연습 하나 안에서 두 값이 어긋나지 않는다
- Android 는 `NoiseSuppressor` 를 소리 환경과 상관없이 켠다. iOS 음성 처리 모드는 이미 소음 억제를 함께 한다

## 이유

후보 1은 ONNX Runtime 네이티브 라이브러리를 Android 에 ABI 마다, iOS 에 따로 넣어야 한다. 앱 크기가 몇 MB 늘고, iOS 는 Kotlin/Native 에서 부를 연결을 새로 만들어야 하며, 모델 파일과 런타임 두 개의 라이선스와 버전을 따로 관리한다. 우리가 거를 것은 물소리처럼 주기가 없는 잡음이라 작은 계산으로 가른다. 후보 2는 두 플랫폼이 다른 판정을 하게 되어 같은 테스트로 볼 수 없다. 후보 3은 공통 코드 몇십 줄이고 합성한 목소리와 잡음으로 commonTest 에서 본다.

끊기는 코치가 지금 말하는 중인지, 그 턴의 재생 길이, 설정의 말로 끊기를 알아야 정한다. 셋 다 세션이 가지고 있다. 라이브러리에 두면 라이브러리가 코치 턴을 알아야 해서 다른 모듈 의존 없이 떼어 쓰는 조건이 깨진다.

## 결과

- 주기가 있는 소리(음악, TV 말소리)는 말소리로 친다. 샤워 중 음악 때문에 코치가 끊기면 학습된 감지 모델(후보 1)을 다시 본다
- 떨리지 않는 자음으로 시작하는 말은 첫 조각이 빠질 수 있다. 말이 이어지면 서버가 뒷부분으로 알아듣는다
- `VOICED_SIMILARITY`, `BARGE_IN_AFTER`, `BARGE_IN_GAP` 은 물소리를 튼 실기기에서 다시 잰다. 값을 바꾸면 상수와 테스트를 같이 고친다
- 이어폰 모드는 바뀌지 않는다. 끊기는 서버 음성 감지가 정한다
- 외부 라이브러리를 넣지 않아 `THIRD_PARTY_LICENSES.md` 에 더할 것이 없다
