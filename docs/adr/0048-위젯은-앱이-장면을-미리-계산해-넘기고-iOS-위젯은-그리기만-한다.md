# 0048. 위젯은 앱이 장면을 미리 계산해 넘기고 iOS 위젯은 그리기만 한다

- 상태: 채택
- 날짜: 2026-11-20

## 배경

오늘 복습 위젯은 오늘 남은 장 수와 이번 주 복습한 날 수를 보이고, 복습을 끝낼 때, 연습 정리가 끝날 때, 날짜가 바뀔 때 다시 그린다(F19.6, F19.7). 두 수는 카드와 복습한 날로 정해지고 연습 탭의 오늘 복습 카드와 같은 계산이다. Android 위젯은 앱 프로세스에서 돌아 DB 를 읽을 수 있다. iOS 위젯 확장은 앱과 다른 프로세스이고 앱의 DB 와 Kotlin 프레임워크를 갖고 있지 않다. 날이 바뀌는 새벽 4시에 앱이 깨어 있다는 보장도 없다.

## 후보

1. 계산은 공통 코드 순수 함수 하나(`reviewWidgetAt`, `upcomingReviewWidgets`)로 한다. Android 는 그릴 때 DB 를 읽어 계산하고 다음 날 새벽 4시나 그 전에 카드가 복습 시각이 되는 때의 알람으로 다시 그린다. iOS 는 앱이 지금 장면과 앞으로 7번의 새벽 4시 장면, 그 사이 카드가 복습 시각이 되는 때의 장면을 문구까지 만들어 App Group 저장소에 쓰고, 위젯 확장은 그 목록을 시각 순서대로 보이기만 한다
2. iOS 위젯 확장에 Kotlin 프레임워크를 링크하고 DB 를 App Group 폴더로 옮겨 위젯이 직접 계산한다
3. Android 도 Glance 로 그린다

## 결정

1을 고른다.

- 계산과 문구는 `apps/opic/shared` 공통 코드에 둔다. 위젯 문구는 공통 Compose 리소스 문자열이다
- Android 는 `RemoteViews` 와 `AppWidgetProvider` 로 그린다. 앱이 카드와 복습한 날 Flow 를 지켜보다 값이 바뀌면 다시 그리고, 날 바뀜과 낮에 카드가 복습 시각이 되는 때는 `RTC` 알람으로 위젯 갱신 방송을 보낸다. 날 바뀜 알람이 그린 값을 Flow 는 모르므로 Flow 는 같은 값도 거르지 않는다. 주기 갱신은 끈다
- iOS 는 앱(Kotlin `IosShell.watchReviewWidget`)이 장면 목록을 JSON 으로 App Group 저장소의 `UserDefaults` 에 쓰고, 앱 틀(Swift)이 `WidgetCenter` 로 다시 그리라고 알린다. 위젯 확장은 Swift 파일 하나로 목록을 읽어 타임라인 항목으로 넘긴다
- App Group 이름은 `group.io.github.nosorae.aiopic` 이다. 앱과 위젯의 entitlements 파일, Kotlin `IosShell.kt`, `ReviewWidget.swift` 에 같은 값이 있다
- 누르면 두 플랫폼 모두 복습 링크(`malhaebom://review`)로 앱을 연다

## 이유

2는 위젯 확장에 앱 크기의 Kotlin 프레임워크가 하나 더 실리고, 위젯 확장이 쓸 수 있는 메모리가 작아 DB 를 열다 시스템이 확장을 끝낼 수 있다. DB 를 App Group 폴더로 옮기는 이전 코드도 생긴다. 미리 계산하면 위젯은 글 두 줄만 읽고, 계산이 공통 코드 하나라서 앱 안 카드와 숫자가 어긋나지 않는다. 복습 알림(ADR 0047)이 iOS 에서 7일 치를 미리 거는 것과 같은 방식이라 앱을 열 때 다시 계산하는 때도 같다.

3은 의존을 하나 더하는데, 위젯이 글 두 줄과 누르기 하나뿐이라 `RemoteViews` 레이아웃 파일 하나로 된다.

## 결과

- 미리 넘긴 장면은 그 사이 복습하지 않는다고 보고 센다. 앱에서 복습하면 다시 계산해 바꾼다
- iOS 는 7일 넘게 앱을 열지 않으면 마지막 장면이 그대로 남는다. 앱을 열면 다시 쓴다
- FSRS 는 다음 복습 시각을 새벽 4시에 맞추지 않아 낮에 복습 시각이 되는 카드가 있다. 두 플랫폼 모두 그 시각에 장면을 바꿔 연습 탭의 오늘 복습 카드와 숫자를 맞춘다
- 문구를 앱이 만들어 넘기므로 위젯 확장에는 위젯 고르기 화면의 견본 문구와 앱을 아직 열지 않았을 때의 숫자 없는 문구만 Swift 에 있다
- iOS 진행 알림의 Live Activity(F16.10)는 이 확장에 아직 붙이지 않았고 그래프의 `live-activity` 노드로 남겼다. 지금은 잠금 화면의 지금 재생 중 표시가 연습 중임을 보인다
