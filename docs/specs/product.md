# 제품 요구사항

실제 오픽 한 회를 그대로 체험하는 모의고사와, 질문 하나만 푸는 한 문항 연습을 주는 앱이다. 답변마다 AI 피드백이 쌓이고, 모의고사는 예상 등급 범위가 나온다. 모의고사는 앱을 껐다 켜도 이어서 풀 수 있어 틈새 시간에 나눠 본다. Compose Multiplatform 으로 Android, iOS 를 같이 만들고 오픈소스로 공개한다.

설계는 `design.md`, 설계 결정은 `../adr/` 에 있다.

## 1. 목표

오픽 AL 을 목표로 하는 사용자가 실제 시험과 같은 조건에서 연습하고, 답변마다 무엇을 고칠지 안다.

## 2. 범위

넣는 것: 모의고사 15문항, 이어 보기, 한 문항 연습, 답변별 피드백, 회차 예상 등급, 회차별 기록, 약점 출제, 틀린 교정 표시, 분석 모델 고르기, 라이브 코치, 손을 쓰지 않는 말하기 연습과 표현 카드 복습(F16~F20).

첫 버전의 AI 제공사는 Gemini 하나다. 분석 구조는 음성을 못 듣는 제공사(Claude, OpenAI 텍스트 모델)도 붙일 수 있게 나눠 둔다(F5.9). 그 제공사들의 실제 연결은 다음 버전에서 한다.

| 뺀 것 | 이유 |
|---|---|
| 서버, 계정 | 사용자가 자기 AI 제공사 키(첫 버전은 Gemini)를 쓴다 |
| Claude, OpenAI 실제 연결 | 첫 버전은 구조만 열어 둔다. 음성을 못 듣는 제공사의 두 단계 경로는 가짜 제공사 테스트로만 확인한다 |
| 정한 시각에 울리는 전화 | 알람 권한, 꽉 찬 화면 권한, 재부팅 재등록, iOS AlarmKit 처리가 따라붙는데 연습의 핵심이 아니다 |
| 3문항 짧은 회차 | 한 문항 연습이 그 역할을 한다 |
| 채점 정확도 측정, 직접 채점 정답지 | 정답 등급을 얻으려면 실제 시험을 보거나 직접 채점해야 한다. 틀린 교정 표시가 쌓이면 나중에 정답지로 쓴다 |
| 화면 복습에서 말한 답을 AI 가 판정하기 | 화면 복습은 사용자가 스스로 평가를 누르는 것으로 먼저 쓴다. 판정이 틀리면 복습 자체를 믿지 않게 된다. 연습 시작 때 말로 하는 복습 3장만 코치가 판정한다(F16.8) |
| 시험일에 맞춰 복습 간격을 좁히는 모드 | FSRS 기본 계산으로 먼저 쓴다 |
| 표현 카드 공유, 기기 사이 맞추기 | 서버가 없다. 카드는 기기에만 둔다(F17.8) |
| 발음 교정 카드 | 말소리만으로 발음을 판정하는 정확도가 낮아서 틀린 카드가 섞인다 |
| 기록 탭의 말하기 연습 기록 | 다음 판에서 더한다. 이번에는 연습 정리 화면과 표현 탭에서만 본다 |
| 1일 뒤 재출제와 7일 뒤 재출제 비교 | 이번에는 7~14일 재출제(F16.5) 하나로 쓴다. 주제별 마지막 연습 시각과 첫 질문이 연습 기록에 남아 다음 판에서 비교할 수 있다 |
| 영어 면접 단계(행동 면접, 기술 결정 설명, 가정 질문)와 목표 단계 설정 | 이번 목표는 AL 이다. AL 다음 단계는 다음 판에서 유형과 꼬리 질문을 더해 연다 |

## 3. 사용자 흐름

**처음 실행.** 시스템 스플래시가 떠 있는 동안 앱이 키와 동의 상태를 읽고 갈 곳을 정한다. 키가 없으면 키 입력 화면에 머문다. 키 입력 화면은 제공사를 고르고 키를 넣는 구조인데 첫 버전에는 Gemini 만 보인다. 키를 넣은 뒤 녹음한 음성이 Google Gemini 로 간다는 안내에 동의해야 모의고사 탭으로 간다. 두 플랫폼 모두 같다.

**모의고사.** 서베이(지난 선택으로 채워져 있음), 수준 선택(1~6), 마이크 점검과 연습 문항, 1~7번, 난이도 재조정, 8~15번 순으로 간다. 끝나면 리포트가 나온다. 중간에 앱을 꺼도 다시 켜면 멈춘 문항에서 이어진다.

**한 문항 연습.** 연습 탭에서 Play 를 누르면 약점 유형에서 질문 하나를 바로 읽기 시작하고, 답하면 바로 피드백이 나온다. 연습 탭은 Play 전에 어느 약한 유형에서 낼지 보인다.

**리포트와 기록.** 답변마다 전문, 교정, 한 등급 위 표현, 시제와 문단 길이와 속도와 멈춤을 본다. 모의고사는 예상 등급 범위와 근거가 붙는다. 기록 화면은 회차별 예상 등급 변화와 한 문항 연습 답변을 함께 보여 준다. 리포트와 기록에는 어느 모델이 분석했는지가 보인다.

**말하기 연습.** 샤워, 운동, 집안일처럼 손과 눈이 바쁠 때 코치와 음성으로 대화한다. 연습 탭 맨 위의 말하기 연습 카드를 누르고 시간과 소리 환경을 골라 시작하면, 그 뒤로는 화면을 꺼도 계속된다. 코치가 주제 하나를 골라 묘사, 습관, 지난 경험, 비교 차례로 묻는다. 멈추기와 끝내기는 말, 이어폰 버튼, 알림 버튼으로 한다. 끝나면 대화 전문에서 고칠 표현과 몰랐던 표현이 카드로 만들어져 표현 탭에 쌓인다.

**표현 복습.** 지하철이나 기다리는 시간에 표현 탭이나 연습 탭의 오늘 복습 카드에서 한 번에 6장을 복습한다. 정답을 가린 채 먼저 말해 보고 열어서 스스로 평가한다. 다음 복습 날짜는 FSRS 로 정한다. 복습 알림과 홈 화면 위젯은 남은 장 수만 알린다.

**모델 고르기.** 설정에서 분석 모델을 고른다. 처음에는 안정(Stable) 모델이 골라져 있다. 미리보기 모델을 고르면 2주 공지로 내려갈 수 있다고 안내한다.

### 화면 목록

앱을 켜면 시스템 스플래시가 떠 있는 동안 갈 곳을 정한다(S0, 그리는 화면이 아니다). 이동은 아래 탭 다섯(모의고사, 연습, 표현, 기록, 설정)이 기본이다. 하위 화면의 탭 표시는 플랫폼마다 다르다. ## 4. 기능 요구사항

각 항목이 수락 기준이다. 테스트로 확인할 수 있게 쓰고, 이슈와 테스트가 이 번호를 가리킨다.

### F1. 첫 실행

- F1.0 앱은 시스템 스플래시(Android SplashScreen API 의 `setKeepOnScreenCondition`, iOS 실행 화면)를 잡아 둔 채 저장된 상태만 읽고, 키가 없으면 S1, 동의 전이면 S2, 둘 다 되어 있으면 모의고사 탭으로 보낸다. 스플래시를 따로 그리지 않는다. 키 확인 요청은 여기서 보내지 않는다
- F1.1 제공사를 고르고 키를 넣으면 그 제공사에 짧은 요청을 보내 키가 맞는지 확인한다. 틀리면 이유를 보여 주고 저장하지 않는다. 첫 버전의 제공사 목록에는 Gemini 하나만 보인다. 키 입력 화면에서 시스템 브라우저로 제공사의 키 발급 페이지(Gemini 는 https://aistudio.google.com/apikey)를 열 수 있다. 키는 가리지 않고 보이며 지우기 버튼으로 비울 수 있다. 확인 전에 붙여 넣으며 딸려 온 글자를 뺀다. 공백과 줄바꿈, 마크다운 이스케이프 역슬래시, 눈에 안 보이는 문자(U+200B~U+200D, U+2060, U+FEFF)다. 키 글자(영문, 숫자, `.`, `-`, `_`)는 그대로 둔다.
- F1.2 키는 제공사마다 따로 저장하고 제공사 이름으로 구분한다. Android 에서 Keystore AES-GCM 키로 암호화해 DataStore 에, iOS 에서 Keychain(`AfterFirstUnlockThisDeviceOnly`)에 둔다. 한 제공사 키를 지워도 다른 제공사 키는 남는다
- F1.3 두 플랫폼 모두 동의 전에는 어떤 녹음도 전송하지 않는다. 동의는 사용자가 버튼을 눌러야 성립하고, 뒤로가기나 홈으로 나가는 것은 동의가 아니다. 동의 화면은 마이크 권한 요청(S6)보다 먼저 나온다. 설정에서 동의를 철회하면 대기 중인 전송도 멈추고 다음 실행 때 S2 로 간다. 동의 화면은 Gemini 무료 등급으로 보낸 음성이 Google 제품 개선에 쓰일 수 있다고 알린다. 키 입력 화면과 모델 선택 화면은 이 안내로 연결만 한다

### F2. 모의고사 진행

- F2.1 화면 순서는 서베이, 수준 선택, 점검, 연습 문항, 1~7번, 재조정, 8~15번, 끝이다. 수준 1~2 는 12문항이다
- F2.2 서베이 Part 4 는 네 묶음마다 최소 개수(2, 1, 1, 1)를 채우고 합쳐서 12개 이상이어야 다음으로 간다. 지난 선택(설정에서 바꾼 답 포함)을 미리 채운다
- F2.3 문항 화면에 질문 글자는 없다. Play 를 누르면 질문을 기기 음성으로 읽고 끝나면 녹음이 저절로 시작된다
- F2.4 녹음 시작 5초 안에만 다시 듣기 한 번. Next 는 녹음 10초 뒤에 켜진다. 지나간 문항으로 못 간다
- F2.5 40분 타이머는 1번에서 시작하고 문항 화면을 벗어나 있는 동안(나가기, 앱 종료) 멈춘다. 기기 시각을 바꿔도 흔들리지 않는다
- F2.6 40분이 지나면 답한 문항까지만 채점하고 남은 문항은 "시간 부족"으로 표시한다
- F2.7 문항별 답변 타이머는 기본으로 끄고 설정에서 켠다

### F3. 이어 보기

- F3.1 진행은 공통 코드의 순수 함수 하나가 계산한다. 상태가 바뀔 때마다 통째로 저장한다
- F3.2 녹음은 몇 초 단위 조각 파일로 바로 쓴다. 앱이 죽으면 쓰던 조각 하나만 잃는다
- F3.3 다시 켜면 같은 문항에서 이어 녹음한다. 그 문항에서 다시 듣기를 안 썼으면 한 번 들을 수 있다
- F3.4 진짜 전화나 Siri 가 끼어들면 그 구간을 표시하고, 끝나면 새 조각으로 다시 녹음한다
- F3.5 화면이 꺼지거나 다른 앱으로 가도 녹음은 이어진다(Android 마이크 서비스, iOS 백그라운드 오디오)
- F3.6 이어 볼 회차가 있을 때 새로 시작하면 먼저 묻는다. 시작하면 앞 회차는 미완료로 끝나 기록에 남고, 답한 문항의 녹음과 분석은 지우지 않는다. 리포트는 미완료라고 표시하고 남은 문항을 "답하지 않음"으로 붙이며, 답한 문항이 없으면 등급을 기다리지 않고 등급이 없다고 쓴다(#223)

### F4. 한 문항 연습

- F4.1 연습 탭에서 언제든 Play 한 번으로 시작한다. 질문 하나, 모의고사와 같은 문항 규칙
- F4.2 답하면 피드백을 바로 보여 준다

### F5. AI 분석

- F5.1 Next 를 누르면 그 답변을 바로 분석 대기열에 넣는다. 15개를 한꺼번에 보내지 않고 순서대로 보낸다
- F5.2 답변 피드백: 전문, 교정(원문 구절과 고친 문장), 한 등급 위 표현, 시제 유지, 문단 길이, 말 속도, 멈춘 시간, 롤플레이에서 한 질문 수
- F5.3 회차 등급: 15번이 끝나면 답변 피드백과 녹음을 묶어 한 번 보낸다. ACTFL 기준 문장을 예/아니오 체크리스트로 채우고, 체크 결과로 등급 범위(예: IH ~ AL)와 근거를 정한다
- F5.4 앱 코드 검사: 교정의 원문 구절이 전문에 있어야 한다. 값 범위, 문항 수, 주제를 확인한다. 통과 못하면 한 번 다시 요청하고 그래도 안 되면 그 항목을 버린다
- F5.5 무음, 한국어, 5초 미만 녹음이면 이유 코드를 돌려받고 "평가할 수 없음"으로 보여 준다. 녹음 내내 말소리 크기(음량 0.2, -40dB)에 닿지 않은 답은 보내지 않고 "말소리가 들리지 않았습니다"로 끝낸다(#241)
- F5.6 오프라인이면 녹음은 그대로 하고 분석은 대기열에 둔다. 429, 408, 5xx 만 지수 백오프로 최대 3회 재시도한다. 실패해도 녹음은 남는다
- F5.7 기본 모델은 앱이 정한 안정 모델 하나로 고정한다. 사용자가 바꾸면 그 모델을 쓴다. 답변 결과마다 `provider`, `model`(모델 id), `promptVersion` 을 저장하고 리포트와 기록에 보여 준다. 한 회차 안에서 답변 분석 모델이 섞이면 회차 등급 옆에 표시한다
- F5.8 설정에서 분석 모델을 고른다. 목록은 앱이 들고 있는 검증된 목록이다. 항목마다 모델 id, 표시 이름, 음성 직접 분석 가능 여부, 안정 또는 미리보기를 둔다. 제공사 모델 목록 API 로는 오디오 지원 여부를 알 수 없고, 출력 검사(F5.4)를 모델마다 확인해야 해서다. 미리보기 모델을 고르면 2주 공지로 내려갈 수 있다고 안내한다. 고른 모델이 내려가 요청이 실패하면 기본 모델로 돌리고 사용자에게 알린다
- F5.9 분석은 두 단계로 나눌 수 있게 만든다. 받아쓰기(전문과 단어 시각)와 글 분석(교정, 표현, 체크리스트, 등급)이다. 음성을 직접 듣는 모델(Gemini)은 두 단계를 한 번 호출로 처리한다. 음성을 못 듣는 제공사는 기기 음성 인식이나 다른 제공사로 받아쓴 뒤 글만 보내고, 발음 항목은 "평가 안 함"으로 표시한다. 첫 버전은 이 경로를 테스트 안의 가짜 제공사로만 끝까지 돌린다

### F6. 출제

- F6.1 Gemini 가 서베이 주제, 수준, 재조정 선택, 약점 점수를 받아 문항 유형 순서에 맞춰 질문을 만든다
- F6.2 생성이 실패하면 앱에 넣어 둔 문항 풀에서 서베이 주제로 고른다. 내장 문항은 직접 쓴다. 기출 원문은 넣지 않는다
- F6.3 사용자는 자기 문항 파일(JSON)을 불러올 수 있다

### F7. 리포트와 기록

- F7.1 답변 리포트: F5.2 의 항목. 한 문항 연습과 모의고사 답변이 같은 화면을 쓴다
- F7.2 회차 리포트: 등급 범위, 근거, 어느 문항에서 무너졌는지, 15개 답변 목록
- F7.3 기록: 회차별 예상 등급 변화, 문항 유형별 약점
- F7.4 기록 목록에 모의고사 회차와 한 문항 연습 답변(한 문항이 한 줄)을 저장한 순서로 섞어 최근 것부터 보인다. 회차는 등급, 연습은 문항 유형과 점수를 보이고, 분석 중과 분석 실패도 그 줄에 보인다. 연습 줄을 누르면 그 답변 리포트가 열린다. 두 종류가 다 있으면 전체, 모의고사, 연습으로 거른다

### F8. 틀린 교정 표시

- F8.1 교정 항목마다 "틀림"을 누를 수 있다
- F8.2 틀림으로 표시한 교정은 약점 점수 계산에서 뺀다
- F8.3 표시한 교정은 원래 답변 전문, 교정 내용, `provider`, `model`, `promptVersion` 과 함께 기기에 남는다. 설정에서 JSON 으로 내보낼 수 있다. 서버가 없으니 사용자가 원하면 저장소 이슈에 붙인다
- F8.4 쌓인 표시는 프롬프트를 고칠 때 오류 분석 재료로 쓴다(`docs/error-analysis.md`)

### F9. 화면 모드

- F9.1 설정에서 화면 모드를 "시스템 따라가기", "라이트", "다크" 중에서 고른다. 기본값은 시스템 따라가기다. 두 플랫폼이 같은 화면을 쓴다. Android 9 기기는 시스템 다크 설정이 없어서 앱 안 선택이 없으면 다크를 쓸 수 없다

### F10. 라이브 코치 진입과 목표 등급

- F10.1 연습 탭의 질문 줄과 기록 탭의 약점 유형에 "코치와 스크립트 만들기" 버튼이 있다. 누르면 시작 시트가 뜬다
- F10.2 시작 시트에서 목표 등급(IM1, IM2, IM3, IH, AL)을 고른다. 기본값은 설정의 목표 등급이다
- F10.3 목표 등급은 사용자 전역 설정 하나다. 설정 화면에서도 바꾼다. 시작 시트에서 바꾸면 전역 값도 바뀐다
- F10.4 전역 값이 없으면 IH 다
- F10.5 시작 시트에 이어폰을 권하는 한 줄과 예상 시간(최대 30분)을 보인다

### F11. 라이브 코치 대화 세션

- F11.1 세션은 네 단계(경험 끌어내기, 표현 코칭, 리허설, 피드백)이고 화면 위쪽에 지금 단계를 보인다
- F11.2 코치는 영어로만 말한다. 사용자가 한국어로 말해도 알아듣고 영어로 답한다
- F11.3 코치는 한 번에 두 문장까지 말하고, 답을 대신 지어 주지 않고 질문으로 끌어낸다
- F11.4 사용자가 코치 말 도중에 말하면 코치가 멈춘다
- F11.5 단계는 코치의 도구 호출과 사용자의 "다음 단계" 버튼 둘 다로 넘어간다
- F11.6 "잠깐 생각할게요"를 누르면 연결을 닫고 타이머를 멈춘다. 다시 누르면 이어 붙인다
- F11.7 세션 상한은 대화 시간 30분이다. 멈춘 시간은 세지 않는다. 25분에 안내하고, 30분이 되면 스크립트 정리로 넘어간다
- F11.8 앱이 백그라운드로 가면 일시정지하고, 돌아오면 이어 붙인다. 연결 핸들이 만료됐으면(2시간) 저장된 메모로 새 연결을 연다
- F11.9 네트워크가 끊겨도 받아쓰기와 메모는 남고 "다시 연결" 버튼을 보인다

### F12. 라이브 코치 화면

- F12.1 받아쓰기는 말풍선 없이 위아래로 쌓고, 지금 말하는 쪽에 목소리 띠를 보인다
- F12.2 소재 메모는 장소, 사람, 사건, 느낌 네 칸이다. 코치가 채우고 사용자가 고친다
- F12.3 표현 카드는 사용자가 한 말, 영어 표현, 등급을 보인다
- F12.4 세션 비용을 보인다. 누르면 유료 등급 단가로 계산한 값이라고 설명한다

### F13. 리허설과 피드백

- F13.1 리허설은 Live 연결을 닫고 기존 녹음기로 녹음한다. 받아쓰기만 글 모델에 맡긴다
- F13.2 피드백은 받아쓰기와 메모를 지시에 넣어 Live 연결을 새로 열고, 잘한 점 하나와 고칠 점 둘을 말한다
- F13.3 리허설은 최대 두 번이다

### F14. 스크립트

- F14.1 세션이 끝나면 받아쓰기, 메모, 표현 카드, 목표 등급을 글 모델에 한 번 보내 스크립트(도입, 본문, 마무리, 쓴 표현)를 만든다. 사용자가 실제로 말한 문장을 최대한 쓴다
- F14.2 스크립트 길이는 목표 등급별 표를 따른다. 이 표는 이 앱이 정한 연습 기준이며 ACTFL 값이 아니다

| 목표 등급 | 말하는 시간 | 문장 수 |
|---|---|---|
| IM1, IM2 | 1분 안팎 | 8~10 |
| IM3 | 1분 15초 안팎 | 10~12 |
| IH | 1분 30초~2분 | 12~16 |
| AL | 2분~2분 30초 | 16~20 |

- F14.3 세 칸(도입, 본문, 마무리)은 바로 편집하고 자동 저장한다. 원본을 따로 보관해 원본 보기와 되돌리기를 할 수 있다
- F14.4 "목표 등급에 맞게 다듬기"로 지금 목표 등급 길이에 맞춰 다시 쓴다
- F14.5 "이 스크립트로 연습"을 누르면 연습 탭의 그 질문으로 가고, 녹음 화면에서 스크립트를 접고 편다
- F14.6 질문 하나에 스크립트를 여러 개 둘 수 있다. 기록 탭에서 "스크립트"로 거른다

### F15. 실시간 음성 동의와 신고

- F15.1 첫 세션 전에 실시간 음성 전송 동의를 받는다. 기존 녹음 파일 전송 동의(F1.3)와 따로 받는다
- F15.2 개인정보처리방침과 스토어 데이터 신고에 실시간 음성 전송을 더한다

### F16. 말하기 연습 세션

- F16.1 연습 탭 맨 위에 말하기 연습 카드와 오늘 복습 카드(F18.10)를 둔다. 말하기 연습 카드는 기본 연습 시간과 지난 연습 날짜를 한 줄로 보이고, 누르면 연습 시작 시트가 뜬다
- F16.2 시작 시트에서 시간(10, 20, 30분)과 소리 환경(이어폰, 스피커)을 고른다. 시간은 설정의 기본 연습 시간(처음 20분)이 골라져 있고, 소리 환경은 이어폰이 연결돼 있으면 이어폰, 아니면 스피커가 골라져 있다. 고른 값은 이번 연습에만 쓴다. 시트에는 말로 하는 조작 안내("잠깐, 다시 시작, 힌트, 이거 영어로 뭐야, 다음 질문, 다른 주제, 그만할래 라고 말하면 돼요")와 고른 시간으로 계산한 대략의 비용(유료 등급 단가로 계산했다는 설명)을 보이고, 스피커를 고르면 휴대폰을 물이 닿지 않는 곳에 마이크가 나를 향하게 두라고 안내한다
- F16.3 키가 없으면 시작 버튼을 흐리게 두고 키를 먼저 넣으라고 안내한다. 실시간 음성 전송 동의(F15.1)를 받기 전에는 시작하지 않는다. 마이크 권한을 아직 묻지 않았으면 묻고, 거부돼 있으면 이 앱의 기기 설정 화면을 연다. 알림 권한을 아직 묻지 않았으면 시작할 때 묻는다
- F16.4 연습은 앱 화면이 보일 때만 시작하고, 시작한 뒤에는 화면을 끄거나 다른 앱으로 가도 계속된다. 연습 중 화면에서 뒤로 가면 연습 탭으로 가고 "연습은 계속돼요. 알림에서 돌아올 수 있어요" 를 안내한다
- F16.5 연습 한 번은 주제 하나다. 코치가 주제를 골라 처음에 말하고, 주제를 고르는 화면은 없다. 마지막 연습 뒤 7~14일이 지난 주제가 있으면 그 가운데 마지막 연습이 가장 오래된 주제를 고르고, 지난번 첫 질문 문장을 그대로 다시 물으며 지난번보다 길게, 이유를 하나 더 넣어 말해 달라고 한다. 그런 주제가 없으면 서베이 주제와 업무 주제 가운데 연습 기록에 가장 적게 나온 주제를 고른다. "다른 주제" 로 바꿀 때도 같은 순서로 고르되 방금 주제는 뺀다. 주제별 마지막 연습 시각은 연습 기록의 주제와 시작 시각으로, 지난번 첫 질문은 그 연습의 다룬 질문 첫 항목으로 찾는다
- F16.6 주제 안에서 다루는 유형은 묘사, 습관, 지난 경험, 비교, 미래 계획, 돌발 상황 여섯이다. 정한 시간이 10분이면 2개, 20분이면 3~4개, 30분이면 5개 유형을 묻는다. 20분 이상이면 돌발 상황을 하나 넣어 예약이 잘못됐다, 배포 중 장애가 났다 같은 문제를 롤플레이로 풀게 한다. 연습 기록에서 문단이 끊기거나 시제가 무너진 일이 많은 유형을 두 번째로 묻는다. 꼬리 질문은 "Why?", "What happened next?", "And before that?" 처럼 한 문장 더, 이유 하나 더 말하게 하는 질문이고, 사용자가 한두 문장으로 끝내면 한 번 더 묻는다. 질문할 때마다 질문 문장과 유형을 진행 중인 연습의 다룬 질문에 적는다
- F16.7 코치는 영어로 한 번에 두 문장까지 말하고, 사용자가 말하는 시간이 절반 이상이 되게 짧게 말한다. 연습 중에는 고친 문장을 말하지 않는다. 틀린 문장은 고칠 표현 후보로 적어 두고 고친 표현은 연습이 끝난 뒤 카드로 준다(F17). 사용자가 막히거나 "힌트" 라고 하면 힌트 한 줄만 준다(예: 지난 이야기니까 과거형으로 해 보세요)
- F16.8 설정의 시작 때 말로 복습(처음 켜짐)이 켜져 있고 오늘 복습할 카드 가운데 처음 봄이 아니오인 카드가 있으면 말로 복습 단계로 시작한다. 처음 보는 카드는 말로 시험하지 않는다. 그런 카드 앞 3장(모자라면 있는 만큼)마다 코치가 한국어 상황을 영어 문장 하나로 말하고, 사용자가 영어로 답하고, 맞든 틀리든 코치가 정답 표현을 한 번 말하고, 사용자가 한 번 따라 말한다. 사용자가 모르겠다고 하면 바로 정답으로 넘어간다. 판정은 맞으면 알았음, 틀리면 다시이고, 그 카드의 복습 값을 FSRS 로 고치고 화면 복습의 평가(F18.6)와 똑같이 복습 횟수, 다시 누른 횟수, 복습한 날에 센다. 카드마다 판정, 판정한 시각, 판정 전 복습 값, 더 나은 표현을 진행 중인 연습의 말로 복습 결과에 적는다. 다 풀면 대화 단계로 넘어간다
- F16.9 음성 명령은 일곱이다. 잠깐(일시정지), 다시 시작, 힌트, 이거 영어로 뭐야(짧은 영어 표현 하나를 들려주고 따라 말하게 한 뒤 몰랐던 표현 카드로 저장, F16.23), 다음 질문(같은 주제의 다음 유형), 다른 주제(주제 바꾼 횟수를 하나 올리고 F16.5 순서로 주제를 바꿔 처음부터), 그만할래(확인 없이 끝내기). 코치의 도구 호출로 받는다
- F16.10 멈추기와 끝내기는 말, 이어폰 버튼, 알림 버튼 세 가지로 한다. 이어폰 버튼은 한 번 누르면 일시정지, 다시 누르면 다시 시작이고 다른 누르기는 쓰지 않는다. 진행 알림(iOS 는 잠금 화면 Live Activity)은 지금 상태와 지난 시간을 보이고 상태가 바뀔 때만 고친다. 버튼은 일시정지, 끝내기, 연결이 끊겨 멈췄을 때 다시 연결이다. iOS 잠금 화면 버튼은 잠금을 풀어야 동작하므로 말로 끝내기를 함께 안내한다
- F16.11 끝낼 때 확인 창을 띄우지 않는다. 화면 버튼, 알림 버튼, 말, 시간 다 됨, 오래 일시정지 어디서 끝내도 같은 끝내기를 한다. 효과음을 내고, 진행 중인 연습을 정리 전 상태의 연습 기록으로 옮기고, 연습 정리(F17.4)를 예약한다. 그때까지 한 말과 표현은 저장된다
- F16.12 대답이 없으면 질문을 짧게 바꿔 한 번 더 묻는다. 두 번째에도 없으면 필요하면 말해 달라고 한 번 말하고 일시정지한다. 일시정지가 10분 넘게 이어지면 끝낸다
- F16.13 남은 시간은 정한 시간에서 대화 시간(일시정지한 시간은 빼고)을 뺀 값이다. 남은 시간이 1분이면 코치가 마무리 문장 하나를 말하고, 0이 되면 끝낸다
- F16.14 통화가 오거나, 다른 앱이 소리를 가져가거나, 이어폰을 빼면 일시정지한다. 돌아오면 코치가 이어서 할지 한 번 묻는다
- F16.15 연결이 끊기면 저장된 이어 붙이기 핸들로 3번까지 다시 연결한다. 그래도 안 되면 일시정지하고 진행 알림에 다시 연결 버튼을 보인다. 대화 전문과 저장한 표현은 남는다
- F16.16 진행 중인 연습(단계, 상태, 일시정지한 시각, 대답 없음 횟수, 주제, 주제 바꾼 횟수, 다룬 질문, 지금 질문을 말한 횟수, 내가 말한 시간, 코치가 말한 시간, 말로 복습 결과, 대화 전문, 저장한 표현 수, 이어 붙이기 핸들, 사용량)은 응답마다 기기 DB 에 적는다. 앱 프로세스가 끝났다가 앱을 켜면 진행 중인 연습이 있으면 연습 중 화면으로 이어 간다
- F16.17 설정의 말 끝 기다림(짧게 0.7초, 보통 1초, 길게 1.5초, 처음 보통)을 Live 연결의 침묵 판정 시간으로 넘긴다. 말로 끊기(처음 켜짐)가 꺼져 있으면 코치가 말하는 중에 사용자가 말해도 코치를 끊지 않는다
- F16.18 연습 중 화면은 큰 상태 원과 목소리 띠(듣는 중, 코치가 말하는 중, 일시정지, 다시 연결하는 중), 남은 분, 저장한 표현 수, 젖은 손으로도 누를 수 있는 큰 일시정지와 끝내기 버튼, 기본으로 접힌 대화 보기, 구석의 작은 추정 비용, "화면을 꺼도 계속돼요" 안내를 둔다. 탭은 없다. 끝내기를 누르면 연습 정리 화면으로 바뀐다
- F16.19 상태가 바뀔 때 시작, 일시정지, 다시 시작, 표현 저장, 끝 다섯 가지 서로 다른 효과음을 낸다. 표현이 하나 저장될 때마다 저장한 표현 수가 하나 오른다
- F16.20 같은 질문은 한 연습에서 3회까지 말한다. 남은 시간이 5분이면 첫 질문을 다시 묻고(2회째) 앞에서 나온 표현을 써 보라고 한 번만 말한다. 2회째가 끝나고 2분 넘게 남았으면 "One more time, smoother this time" 처럼 한 번 더 묻는다(3회째). 정한 시간이 10분이면 2회째까지만 한다. 회차마다 말할 시간을 줄이지 않는다. 다룬 질문에 같은 질문을 말한 횟수를 적는다
- F16.21 코치가 뜻을 알아듣지 못했거나 두 가지로 읽히면 "You mean the deadline or the release date?" 처럼 뜻만 짧게 되묻는다. 문법은 고치지 않는다. 이 확인 질문 뒤의 대답은 대답 없음 횟수(F16.12)에 세지 않는다
- F16.22 설정의 연습 중 문법 짚기는 안 짚음(처음 값)과 같은 오류가 세 번 나오면 한 번 짚음 가운데 하나다. 한 번 짚음이면 같은 틀린 유형이 세 번째 나올 때 코치가 정답 없이 "Past tense?" 처럼 한 번 묻고, 사용자가 고쳐 말할 때까지 기다린다. 이 값은 연습을 시작할 때 코치 지시에 넣는다
- F16.23 사용자가 "이거 영어로 뭐야" 라고 하거나 막혀서 한국어를 섞으면 코치가 그 부분의 짧은 영어 표현 하나를 들려주고 따라 말하게 한 뒤 몰랐던 표현 카드로 저장한다. 내가 한 말은 한국어가 섞인 그 문장을 전사된 그대로 두고, 처음 봄은 예, 다음 복습 시각은 다음 날 새벽 4시(F18.11)다. 한국어로 말한 것은 틀린 유형으로 세지 않는다
- F16.24 기기 안 말소리 감지로 사용자가 말한 시간을 재서 진행 중인 연습의 내가 말한 시간에 더하고, 코치 음성을 재생한 길이는 코치가 말한 시간에 더한다. 말로 끊겨 멈춘 코치 음성은 실제로 재생한 만큼만 더한다. 두 값은 끝낼 때 연습 기록으로 옮긴다. 내 말 비율은 내가 말한 시간을 내가 말한 시간과 코치가 말한 시간의 합으로 나눈 값이다

### F17. 연습 정리와 표현 카드

- F17.1 연습이 끝나면 대화 전문을 글 모델에 한 번 보내 표현 카드를 만든다. 카드 종류는 고칠 표현, 몰랐던 표현, 정형 표현, 더 자연스럽게 넷이다. 정형 표현은 "The thing is,", "What I ended up doing was", "mitigate the risk" 처럼 통째로 꺼내 쓰는 연결 표현과 연어(덩어리 표현)다. 더 자연스럽게는 맞게 말했지만 더 자연스럽게 할 수 있는 문장이다. 카드마다 내가 한 말, 더 나은 표현, 한국어 뜻, 틀린 유형(시제, 관사, 낱말 선택, 연결어, 문장 구조. 고칠 표현에만), 상황 한 줄을 받는다. 정리 지시에 틀린 곳만 최소로 고치라고 적는다
- F17.2 카드의 내가 한 말이 대화 전문에 그대로 있어야 저장한다. 없으면 그 카드만 버린다. F5.4 와 같은 검사다. 정형 표현 카드의 내가 한 말은 그 표현을 쓸 수 있었던 사용자 문장이고, 한국어를 섞어 만든 몰랐던 표현 카드는 한국어가 섞인 문장을 전사된 그대로 쓴다. 응답을 읽을 수 없거나 검사를 통과한 카드가 하나도 없으면 한 번 다시 요청한다
- F17.3 한 문장에 틀린 곳이 여럿이면 틀린 곳마다 카드를 따로 만든다. 고칠 표현 카드는 한 연습에 8장까지다. 같은 틀린 유형이 여러 번 나온 것과 뜻 전달을 막은 것을 먼저 고르고, 고르지 못한 오류는 카드로 만들지 않고 연습 기록의 이번에 넘긴 오류 수로만 센다. 더 자연스럽게 카드는 한 연습에 2장까지다. 연습 중에 저장한 몰랐던 표현과 같은 표현이면 새로 만들지 않는다
- F17.4 정리는 분석 작업 표의 작업으로 돈다. 정리 상태는 정리 전, 정리 중, 정리 끝, 정리 실패다. 실패하면 30초, 2분, 10분 간격으로 3번 다시 시도하고 그래도 안 되면 정리 실패로 둔다. 앱을 켤 때 정리 전이거나 정리 실패인 연습이 있으면 다시 예약한다
- F17.5 저장한 카드는 처음 봄을 예로 두고, 다음 복습 시각은 연습을 끝낸 날(F18.11)의 다음 날 새벽 4시로 둔다. 연습 당일에는 정리 화면에서 보는 것까지만 한다. 정리가 끝나면 만든 카드 수, 이번에 넘긴 오류 수, 표현을 쓴 횟수(F17.9)를 연습 기록에 적고, 앱이 보이지 않을 때만 "표현을 정리했어요" 알림으로 새 표현 몇 개가 복습에 들어갔는지 알린다. 알림을 누르면 그 연습의 정리 화면이 열린다
- F17.6 연습 정리 화면은 요약(대화 시간, 내가 말한 시간과 내 말 비율, 다룬 질문, 표현을 쓴 횟수, 만든 카드 수), 말로 복습 결과(F17.10), 카드 목록(내가 한 말, 더 나은 표현, 틀린 유형)을 보인다. 더 자연스럽게 카드는 틀린 유형 대신 "틀린 건 아니에요" 를 보인다. 말 속도와 쉼 횟수는 보이지 않는다. 정리 전이거나 정리 중이면 "표현을 정리하고 있어요" 와 진행 표시를, 정리 실패면 다시 시도 버튼을, 카드가 없으면 이번에는 고칠 표현이 없었다는 문구를 보인다. 이 화면을 거치지 않아도 카드는 저장된다
- F17.7 정리 화면에서 카드를 왼쪽으로 밀면 빼고 되돌리기를 5초 보인다. 카드 줄을 길게 누르면 틀린 지적으로 신고하고 카드를 빼고, 연습 기록의 틀린 지적 신고 수를 하나 올린다. 카드를 누르면 표현 상세가 열린다. "다 봤어요" 는 연습 탭으로 간다
- F17.8 표현 카드, 연습 기록, 진행 중인 연습, 복습한 날은 기기 DB 에만 둔다. 다른 기기와 맞추지 않는다
- F17.9 표현을 쓴 횟수는 연습을 시작할 때 있던 카드의 더 나은 표현과 이번 연습 중 코치가 들려준 표현을 사용자가 대화 전문에서 말한 횟수다. 들려준 직후 따라 말한 것은 세지 않는다. 정리 작업이 센다
- F17.10 정리 화면의 말로 복습 결과는 연습 시작 때 말로 푼 카드마다 더 나은 표현과 판정을 보이고, 비었으면 숨긴다. 판정을 누르면 다시는 알았음으로, 알았음은 다시로 바꾼다. 그 카드의 복습 값을 판정 전 복습 값으로 되돌린 뒤 바뀐 판정으로 FSRS 를 다시 계산하고, 다시로 바뀌면 다시 누른 횟수를 하나 올리고 알았음으로 바뀌면 하나 내린다. 그 카드의 마지막 복습 시각이 판정한 시각보다 늦으면 바꿀 수 없고, 그 뒤에 다시 복습해서 바꿀 수 없다는 작은 글을 보인다

### F18. 표현 탭과 복습

- F18.1 아래 탭은 모의고사, 연습, 표현, 기록, 설정 다섯 개다. 표현 탭은 맨 위에 오늘 복습 카드(남은 장 수, 남은 분, 이번 주 복습한 날 수, 시작 버튼), 그 아래 자주 틀리는 유형(고칠 표현 카드만 틀린 유형마다 세어 많은 순으로, 카드가 없으면 숨김), 묶음 칩(전체, 고칠 표현, 몰랐던 표현, 정형 표현, 더 자연스럽게, 보관함. 처음 전체), 표현 목록(새로 만든 순, 더 나은 표현과 한국어 뜻과 틀린 유형)을 둔다. 목록 줄에서 더 자연스럽게 카드는 틀린 유형 대신 "틀린 건 아니에요" 를, 몰랐던 표현과 정형 표현은 종류 이름을 보인다. 보관함은 보관한 카드만 보인다. 목록이 비면 말하기 연습을 하면 표현이 쌓인다는 문구와 연습 시작 버튼을 보인다
- F18.2 오늘 복습할 카드는 보관하지 않은 카드 가운데 다음 복습 시각이 지금보다 이른 것을 잊었을 확률이 높은 순으로 세운다. 처음 봄이 예인 카드(새 카드)는 오늘 새로 보여 준 수(마지막 복습 시각이 오늘이고 복습 횟수가 0인 카드 수)와 합쳐 10장이 될 때까지만 만든 순으로 넣는다. 다만 다음 복습 시각에서 하루가 넘게 지난 새 카드는 10장 상한과 상관없이 넣고 줄 맨 앞에 둔다. 오늘 이미 복습한 수(마지막 복습 시각이 오늘인 카드 수)를 빼고 하루 30장까지 자른다. 오늘 남은 시간은 장 수에 20초를 곱해 분으로 올림한다
- F18.3 표현 상세는 내가 한 말(틀린 부분 밑줄), 더 나은 표현과 듣기 버튼(기기 음성), 한국어 뜻, 상황, 복습 기록(복습 횟수, 다시 누른 횟수, 다음 복습 날짜)을 보인다. 상세에 들어오면 그 카드의 처음 봄을 아니오로 바꾼다. 상세에서 읽는 것은 복습으로 세지 않는다. 고치기로 더 나은 표현과 한국어 뜻을 고친다. "이미 알아요" 는 카드를 빼지 않고 FSRS 쉬움으로 평가해 간격만 늘리고 "다음 복습까지 간격을 늘렸어요" 를 안내한다. 보관한 카드에서는 숨긴다. "필요 없어요" 는 잘못 만들었거나 쓸모없는 카드를 보관함으로 보내 복습에서 빼고, 보관한 카드에서는 "꺼내기" 로 바뀌어 다시 복습에 넣는다. 삭제는 "이 표현을 지울까요? 복습 기록도 함께 지워져요" 확인 뒤에 지우고 표현 탭으로 간다
- F18.4 복습 한 묶음은 오늘 복습할 카드 앞 6장이다. 처음 봄이 예인 카드는 종류와 상관없이 가리지 않고 더 나은 표현과 내가 한 말을 보이며 기기 음성으로 읽은 뒤 "소리 내 따라 말해 보세요" 를 띄운다. 처음 봄이 아니오인 카드는 정답을 가린 채 시작한다. 몰랐던 표현과 정형 표현은 한국어 뜻과 상황을 보이고 영어로 말해 보라고 하고, 고칠 표현은 내가 한 말의 틀린 부분을 빈칸으로 가리고 틀린 유형을 작게 붙여 문장 전체를 고쳐 말해 보라고 하고, 더 자연스럽게는 내가 한 말을 보이고 "틀린 건 아니에요, 더 자연스럽게 말해 보세요" 를 붙인다. 한 카드는 틀린 곳 하나만 다룬다
- F18.5 정답 보기를 누르면 더 나은 표현과 내가 한 말을 위아래로 보이고 다른 부분에 색을 칠한다. 소리 없이가 꺼져 있으면 더 나은 표현을 기기 음성으로 읽는다. 소리 없이(처음 꺼짐, 설정에 저장)를 켜면 말해 보라는 문구를 "속으로 말해 보세요" 로 바꾸고 읽지 않는다
- F18.6 평가 버튼은 정답을 연 뒤에 보이는 다시와 알았음 둘이고, 길게 누르면 어려움과 쉬움이 더 나온다. 다시는 Again, 알았음은 Good, 어려움은 Hard, 쉬움은 Easy 로 FSRS 에 넘긴다. 평가하면 그 카드의 복습 값을 FSRS 로 다시 계산하고 복습 횟수를 하나 올린다. 다시면 다시 누른 횟수도 올린다. 오늘이 복습한 날에 없으면 더한다. 처음 봄이 예인 카드는 정답 보기와 평가 버튼 대신 다음 버튼 하나만 둔다. 다음을 누르면 FSRS 평가 없이 처음 봄을 아니오로, 마지막 복습 시각을 지금으로, 다음 복습 시각을 다음 날 새벽 4시로 바꾸고 복습 횟수는 그대로 둔다. 오늘이 복습한 날에 없으면 더한다
- F18.7 목표 기억률은 설정의 복습 양을 따른다. 적게 85%, 보통 90%, 많이 95% 이고 처음은 보통이다
- F18.8 중간에 나가도 누른 평가는 저장되고, 이번 묶음과 지금 카드 순번은 프로세스가 끝나도 남아 다음에 이어 간다. 묶음을 끝내면 복습 끝 시트에 알았음, 다시, 처음 본 장 수와 이번 주 며칠째인지를 보인다. 축하 애니메이션은 이번 주 처음 복습한 날에만 짧게 보인다. 오늘 복습할 카드가 남았으면 "6장 더" 를 보인다
- F18.9 연속 일수는 보이지 않는다. 이번 주 복습한 날 수(이번 주 월요일부터 오늘까지 복습을 한 장 이상 끝낸 날)를 보인다. 복습한 날은 최근 8주만 둔다
- F18.10 연습 탭의 오늘 복습 카드는 오늘 복습할 카드 수와 오늘 남은 시간을 보이고 누르면 복습 화면이 열린다. 할 카드가 없으면 오늘 복습 끝 문구와 이번 주 복습한 날 수를, 표현 카드가 하나도 없으면 말하기 연습을 하면 표현이 쌓인다는 문구를 보인다
- F18.11 앱의 하루는 기기 시간대의 새벽 4시에 바뀐다. 오늘, 다음 날, 복습한 날, 이번 주, 위젯이 다시 그리는 날짜가 바뀔 때는 모두 이 기준이다. 자정에서 새벽 4시 사이에 끝낸 연습과 복습은 전날로 친다

### F19. 복습 알림과 위젯

- F19.1 설정 탭에 말하기 연습 묶음(기본 연습 시간, 말 끝 기다림과 "말하다 끊기면 길게로 바꿔 보세요" 안내, 코치가 말할 때 내 말로 끊기, 연습 중 문법 짚기(F16.22), 연습 시작 때 복습 3장 말로 하기)과 복습 묶음(복습 양, 복습 알림, 알림 시각)을 더한다
- F19.2 복습 알림은 처음에 꺼져 있고 알림 시각은 처음 오후 8시다. 알림이 꺼져 있으면 시각 고르기를 흐리게 보인다. 알림을 켤 때 알림 권한을 아직 묻지 않았으면 묻는다
- F19.3 복습 알림은 하루 한 번 정한 시각에, 오늘 복습할 카드가 하나 이상이고 오늘 아직 복습하지 않았을 때만 보낸다. 제목은 "오늘 복습할 표현이 있어요" 이고 본문은 몇 장, 약 몇 분인지만 쓴다. 재촉하거나 연속 기록이 끊긴다는 말은 쓰지 않는다. 앱을 보고 있으면 띄우지 않는다
- F19.4 iOS 는 알림을 보낼 때 앱 코드를 돌릴 수 없으므로 복습을 끝낼 때, 연습 정리가 끝날 때, 앱이 앞으로 올 때 조건을 미리 계산해 다음 알림을 다시 건다
- F19.5 복습 알림을 누르면 링크 `malhaebom://review` 로 복습 화면이 열린다
- F19.6 홈 화면 위젯은 오늘 남은 장 수와 이번 주 복습한 날 수만 보이고, 할 카드가 없으면 오늘 복습 끝 문구를 보인다. 누르면 복습 화면이 열린다. 위젯 안에서 카드를 풀지 않는다
- F19.7 위젯은 복습을 끝낼 때, 연습 정리가 끝날 때, 날짜가 바뀔 때 다시 그린다. iOS 는 앱과 위젯이 같이 읽는 App Group 저장소에서 값을 읽는다

### F20. 스피커 모드

- F20.1 이어폰이 연결돼 있지 않으면 시작 시트의 소리 환경이 스피커로 골라진다. 스피커 모드는 첫 출시에 포함한다
- F20.2 스피커 모드는 기기 에코 제거와 소음 억제를 켠다
- F20.3 스피커 모드는 기기 안 말소리 감지로 말소리가 아닌 조각(물소리 등)은 보내지 않는다
- F20.4 코치가 말하는 중에는 내 말소리가 0.6초 넘게 이어질 때만 코치를 끊는다. 0.6초는 처음 값이고 실기기에서 재서 정한다
- F20.5 스피커 모드면 Live 연결의 말 시작 감도와 말 끝 감도를 낮게 둔다
- F20.6 물소리를 스피커로 틀어 둔 실기기에서 10분 연습하는 동안 코치가 스스로 끊기지 않는다

| 네이티브 후보(아직 정하지 않음) | 공유 시트, 파일 고르기(F6.3 문항 불러오기, F8.3 내보내기), 텍스트 입력 키보드 위 도구 |

강조색은 Montage 기본 파랑(`#0066FF`) 대신 말하기 등급 표에서 Advanced 구간에 흔히 쓰이는 주홍 계열을 쓴다. 앱의 목표 등급(AL)을 떠올리게 하는 색이다. 다른 기관의 로고나 그림은 쓰지 않고 색만 쓴다. 시맨틱 색 가운데 brand 계열만 이 색으로 바꾼다.

| 쓰는 곳 | 값 | 대비 |
|---|---|---|
| 라이트: 버튼, 글자, 선택 표시 | `#C83F1A` | 흰 글자 대비 5.02:1 |
| 라이트: 등급 그래프, 진행 막대 같은 장식 | `#E9572B` | 흰 글자 대비 3.58:1 이라 글자 배경에는 쓰지 않는다 |
| 다크 | `#FF8A62` | `#1B1C1E` 위 7.36:1. 위에 올리는 글자는 검정 계열 |

다크 배경의 실제 값은 Montage 를 옮기는 노드(`c5`)에서 다시 잰다.

네이티브로 그리는 부분은 미리 확인 노드(`s4`)에서 관리 비용을 잰다. 아래 넷 중 하나라도 해당하면 하단 탭과 뒤로가기도 Montage 로 그려 두 플랫폼을 완전히 통일한다.

1. 네이티브 탭이나 뒤로가기 때문에 플랫폼별 코드가 화면 노드마다 생긴다. 하위 화면 탭 표시 차이(Android 숨김, iOS 유지)를 앱 틀의 화면 경로 표 하나로 처리하지 못하고 화면마다 플랫폼 분기가 생기는 경우도 여기 든다
2. 스크린샷 테스트를 화면마다 플랫폼별로 따로 만들어야 한다
3. 탭 바 높이와 안전 영역 여백을 Android, iOS 두 쪽에서 따로 계산해 Compose 화면에 넘겨야 하고, 그 값이 화면마다 다르게 쓰인다
4. iOS TabView 안에 Compose 화면을 넣었을 때 탭을 오갈 때마다 화면 상태가 사라지거나, 시험 중 탭 숨기기가 한 줄 설정으로 안 된다

## 6. AI 품질 관리

정답 등급 없이 하는 세 가지를 프롬프트를 고칠 때마다 같은 입력으로 다시 돌린다.

1. 같은 입력 5번: 등급이 몇 번 같게 나오는지
2. 일부러 틀린 답: 시제, 관사 오류를 넣은 대본을 기기 음성으로 읽혀 교정이 잡는 비율
3. 수준 다른 답 셋: 같은 문항을 NL, IM, AL 수준으로 써서 등급 순서가 맞는지

결과는 `evals/reports/` 에 프롬프트 버전별 표로 남긴다.

## 7. 완료 기준

- F1~F8 의 수락 기준이 모두 테스트로 확인된다. 진행 상태 계산은 앱 꺼짐, 40분 끝, 7번 뒤 재조정을 포함한 모든 조합을 단위 테스트로 본다
