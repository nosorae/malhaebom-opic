# 개인정보처리방침

시행일: 2026-11-07

말해봄(이하 "앱")는 서버가 없다. 앱을 만든 쪽은 사용자의 녹음, 답변 내용, API 키를 받지도 보관하지도 않는다. 기기 밖으로 나가는 것은 사용자 자신의 API 키로 Google Gemini 에 보내는 요청뿐이고, 답변 녹음은 사용자가 동의한 뒤에만 보낸다. 라이브 코치(코치와 스크립트 만들기)의 실시간 음성은 따로 동의한 뒤에만 보낸다.

## 1. 기기 안에만 두는 데이터

| 데이터 | 쓰는 곳 | 저장 방식 |
|---|---|---|
| 답변 녹음 | 답변 분석, 다시 듣기 | 앱 전용 폴더. 자동 백업과 기기 이전에서 뺀다 |
| Gemini API 키 | Gemini 요청 인증 | Android 는 Keystore 키로 암호화해 앱 저장소에, iOS 는 Keychain(이 기기에서만 열림)에 둔다. 자동 백업과 기기 이전에서 뺀다 |
| 답변 전문, 피드백, 점수, 회차 등급 | 기록과 리포트 화면 | 앱 데이터베이스 |
| "틀림" 표시한 교정 | 약점 점수 계산, 내보내기 | 앱 데이터베이스 |
| 라이브 코치의 받아쓰기, 소재 메모, 표현 카드 | 코치 화면, 다시 연결, 스크립트 만들기 | 앱 데이터베이스 |
| 스크립트(원본과 고친 판) | 스크립트 보기와 연습 | 앱 데이터베이스 |
| 라이브 코치 세션 사용량(토큰 수, 추정 비용) | 세션 비용 표시 | 앱 데이터베이스 |
| 설정(분석 모델, 화면 모드, 목표 등급, 동의 여부) | 앱 동작 | 앱 저장소 |

앱을 지우면 위 데이터가 모두 지워진다. 키는 설정에서 따로 지울 수 있다.

## 2. 기기 밖으로 보내는 데이터

**Google Gemini API 로 보내는 답변 녹음.** 사용자가 음성 전송 동의 화면에서 "동의하고 계속하기"를 눌러야 보낸다. 동의 전에는 어떤 녹음도 보내지 않는다. 요청은 HTTPS 로만 보내고, 사용자가 넣은 API 키로 인증한다. 앱은 Gemini 의 응답(전문, 피드백, 점수)을 기기에만 저장한다.

**라이브 코치에서 Google Gemini API 로 보내는 실시간 음성.** 코치와 대화하는 동안 마이크 음성을 녹음 파일로 만들지 않고 말하는 그대로 Gemini 로 보낸다. 답변 녹음 전송 동의와 별개로, 첫 세션 전에 실시간 음성 전송 동의를 따로 받는다. 동의 전에는 실시간 음성을 보내지 않는다. 요청은 HTTPS 로만 보내고 사용자가 넣은 API 키로 인증한다. 리허설은 녹음 파일로 녹음하고 받아쓰기를 받으려고 Gemini 로 보낸다. 피드백, 다시 연결, 스크립트 만들기 요청에는 그때까지의 받아쓰기, 소재 메모, 표현 카드, 목표 등급을 넣어 보낸다. 앱은 Gemini 의 응답(받아쓰기, 메모, 표현 카드, 스크립트)을 기기에만 저장한다.

Gemini 무료 등급 키로 보낸 음성(답변 녹음과 실시간 음성)과 응답은 Google 이 제품 개선에 쓸 수 있고 사람이 직접 들을 수 있다. 유료 등급의 처리 방식은 사용자와 Google 사이의 약관을 따른다. 자세한 내용은 [Gemini API 추가 약관](https://ai.google.dev/gemini-api/terms)에 있다. Gemini API 는 만 18세 이상만 쓸 수 있고, 무료 등급을 쓸 수 없는 지역이 있다.

**API 키 확인 요청.** 키를 넣을 때 키가 맞는지 확인하려고 Gemini 에 짧은 요청을 한 번 보낸다. 이 요청에는 녹음이 들어가지 않는다.

**사용자가 직접 내보내는 교정 기록.** 설정의 "틀림 표시 내보내기"는 JSON 을 클립보드에 복사할 뿐이다. 어디에 붙여 넣을지는 사용자가 정한다.

앱에는 광고, 분석 도구, 오류 보고 도구가 없다. 위치, 연락처, 기기 식별자를 읽지 않는다.

## 3. 권한

| 권한 | 이유 |
|---|---|
| 마이크 | 답변 녹음, 라이브 코치 대화 |
| 포그라운드 서비스(마이크) | Android 에서 답변 도중 화면이 꺼지거나 다른 앱으로 가도 녹음을 잇는다. 녹음하는 동안만 알림이 뜬다 |
| 인터넷 | Gemini 요청 |

## 4. 동의 철회와 삭제

설정에서 음성 전송 동의를 철회하면 보내려고 기다리던 녹음도 보내지 않고, 다음 실행 때 동의 화면이 다시 나온다. 실시간 음성 전송 동의가 없으면 라이브 코치 세션을 시작하지 않는다. 이미 Google 로 보낸 데이터는 앱이 지울 수 없다. Google 계정의 Gemini API 설정과 Google 의 정책을 따른다.

## 5. 아동

앱은 만 18세 미만을 대상으로 하지 않는다. Gemini API 이용 조건이 만 18세 이상이기 때문이다.
